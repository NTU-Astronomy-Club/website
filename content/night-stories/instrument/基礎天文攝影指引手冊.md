### **天文攝影基本流程概覽**

- **架設**

1. 架設腳架、對北、對水平（全程請確保腳架完全張開、三角板確實安裝、輔以水平儀進行）
2. 放置赤道儀（請確保極軸調整螺絲調整空間充裕）、鎖上重錘（注意重錘方向）
3. 組裝鏡筒、修正鏡組、相機、導星鏡＆導星相機（請先確認天體構圖與相場旋轉角度）
4. 放置主鏡（請確保重錘已安裝再架上主鏡）、鳩尾槽螺絲先鎖大的再鎖保險小螺絲
5. 接上各式電源、Asiair、傳輸線、除霧線、遮光罩
6. 對赤經、赤緯軸平衡（建議兩人合作進行）

- **調整**

1. 尋找接近無線遠目標為主鏡預對焦、對尋星鏡及主鏡光軸水平（尋找遠處同一目標）
2. 於日落前完成上述步驟，如未即時完成請盡速接續下列動作，勿行冗事如拍攝月表等
3. 尋找可見亮星使用魚骨板配合相機live view模式進行對焦（注意星點仰角及大氣擾動 還有把相機的曝光調高）
4. 對極軸（如使用asiair*或NINA等系統，請確保前項完成後再行此動作）、將赤道儀回到home position
5. Goto目標天體或星點密集區域，為導星相機對焦*（亦可參照此前對焦位置進行預對焦）

- **拍攝**

1. 開始拍攝（過程中請注意相機設定*、導星*、中天翻轉、Seeing變化、是否起霧）
2. 天文暮光後(或天關沒事幹的時候)，拍攝暗電流*（可紀錄現場溫度），過程中請確保蓋上鏡頭/筒蓋避免漏光（D800另需注意觀景窗是否關上）
3. 日出後拍攝平場*，以西方、西北方、西南方天空為主
4. 拍攝偏壓*（基本上都有檔案了，但按一下也爽）
5. 曬儀與收拾，或確保物品已收入箱中並呈現足以抵禦野生動物及冗員之狀態
6. 晨喚冗員或拍下儀器過早就寢之罪行，尋找床位或任一不受野生動物侵擾地點休眠。

- 將於後續段落說明

### **相機使用指引**

- 曝光由快門速度、光圈（即焦比，已固定）、ISO決定，請確保參數設定合適
（ISO通常設定：平地800、山上1600 / 快門通常設定：看你對多準）
- 使用D800拍攝時務必開啟Astro Mode，如有斷線情況每次重啟後請重新確認是否開啟
- 使用ASIair、NINA、快門線等設備控制快門時，請將相機設定於B(Bulb)快門
- 天黑前請多摸相機、觀看yt評測影片或附錄指引(如果有的話)，熟悉各按鍵及功能
- 拆裝相機時務必保持感光元件朝下，避免置於塵土多的地方（尤其Z62）

### **導星使用及對拍攝的影響**

- 導星相機設定時須注意曝光時間、gain值、dither（建議每五張一次）
- 對焦時如找不到可用星點，請拉高gain值或微調導星鏡座上螺絲略微改變導星相場位置
- 當赤緯出現大幅變動（如更換目標天體）時，請清除此前導星紀錄重新導星
- 當大氣擾動嚴重時，應拉長導星曝光時間（e.g. 1.5s -> 3s）
- 風大或其他因素造成非追蹤不良的導星誤差時，應暫時關閉導星

### **天文攝影檔案**

- 亮場(light)：天體檔案，曝光時間取決於赤道儀追蹤極限、環境影響
- 暗電流(dark)：修正拍攝時相機產生的熱訊號，曝光時間應與亮場相同，溫度盡量接近
- 平場(flat)：修正亮場中的塵點、暗角，曝光時間請參照相機直方圖（分佈集中於左⅓、¼）
- 偏壓(bias)：修正相機產生影像時的隨機讀出訊號

### **ASIair使用簡介**

- 設備連結＆參數設定
  - 輸入參數：主鏡焦長 C8：2032mm / ED81S：625mm
  - 導星焦長 C8：240*1.6mm / ED81S：200mm
  - 赤道儀
  - 主相機
  - 導星相機
  - 設備連結孔位：相機 USB 3.0 - type c(Z6II) HDMI (D800)
  - 導星相機  USB 2.0 - type c
  - 赤道儀 - USB 2.0  (！！SXD2是以網路線連結Starbook Ten！！） - 畸形孔
  - 赤道儀電源 圓孔 - 圓孔
  - 除霧線 -USB 剩啥插啥 （通常為USB3.0）
- 對極軸
- 導星設定
- goto功能
- sync 功能
- 拍攝計畫設定
- 星點大小檢測（確認Seeing變化）

### **Starbook Ten使用簡介**

！！使用SXD2時必定會用到，請勿喪失此基本技能！！

- 設備連結＆參數設定
  - 經緯度、海拔、時間、home position確認
  - 若需連接ASIair，請確認網路IP
- Chart / Scope mode切換：在Scope mode才能控制赤道儀
- Zoom in / out：如同字面意思，控制赤道儀轉速
- 三星 / 多星校正：找到目標星點or天體時，按下Align鍵以校正目標與星圖
- 天體與home position選取、go to ：請按下object鍵後選取各星表

### **拍攝計畫擬定**

- 建議軟體：Stellarium電腦版、Telescopius

1. 確認觀測地點遮蔽、光害等級（Light Pollution Map）
2. 模擬設備配置（焦長、焦比、感光元件大小、相場旋轉角度）
3. 根據目標所需曝光時間、大小、仰角挑選天體（盡量至少能拍半夜、仰角不低於30度、相場角度不需變更、不要爆框、不要太醜、不要太天馬行空、珍惜難得的拍攝條件）
